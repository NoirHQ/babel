# 통합 계정

## Consolidating Fragmented Accounts Across Protocols

Unified Account는 여러 블록체인 프로토콜에 걸쳐 분산된 계정을 하나의 통합된 구조로 묶어, 프로토콜 간의 차이에도 불구하고 사용자가 데이터 주권을 유지하고 상호운용성을 확보할 수 있도록 설계되었습니다.
Unified Account는 단일 원천, 다중 프로토콜 표현을 제공하며, 여러 프로토콜에서 동일한 암호학 알고리즘을 사용하는 계정을 하나의 계정으로 관리할 수 있게 합니다. AccountId를 설정하고 각 프로토콜별 계정 주소를 이 AccountId에 매핑하여, 프로토콜과 상관없이 내부적으로 일관된 접근점을 제공할 수 있습니다.

## Resolving Protocol Fragmentation

블록체인이 확산되면서 각 체인은 자체적인 스펙을 구축하기 시작했습니다. 일부 체인에서는 동일한 암호학 알고리즘을 사용하지만, 각기 다른 프로토콜 스펙으로 인해 계정이 분리되어 별도의 지갑을 사용해야 하고, 다른 프로토콜의 상태를 직접 제어하거나 접근할 수 없는 경우가 많습니다.

Unified Account는 이러한 문제를 해결하기 위해 다음을 제공합니다:

- 서로 다른 계정 표현을 AccountId에 매핑하여 일관된 관리 경험을 제공합니다.
- AccountId를 통해 프로토콜 간 통합된 상태에 접근할 수 있어, 계정의 파편화를 없앱니다.

프로토콜 종류와 상관없이 동일한 ID를 공유하여, 프로토콜 경계를 넘어서는 트랜잭션(Cross-Protocol Transaction)을 지원해 원활한 상호작용이 가능합니다.

## Unified Account Workflow

1. 인바운드 트랜잭션 (계정 통합 전): 계정이 통합되기 전에는 인바운드 트랜잭션(예: 자산 전송) 발생 시 프로토콜별 계정에 상태가 독립적으로 저장됩니다.
2. 아웃바운드 트랜잭션 및 계정 통합: 사용자가 서명한 최초의 아웃바운드 트랜잭션이 발생하면, 시스템은 서명을 검증하고 AccountId를 식별하여 호환 가능한 모든 프로토콜 계정과 연결합니다. 이 단계에서 시스템은 연결된 계정에 존재하는 네이티브 자산을 AccountId로 전송합니다. 계정 통합 이전에는 네이티브 자산만 존재할 수 있기 때문에, 이 과정은 해당 자산을 통합된 계정으로 일관되게 관리할 수 있도록 하여 프로토콜 간 중앙화된 접근점을 제공합니다.
3. 온체인 저장: 계정이 통합되면 AccountId와 프로토콜별 계정 간의 매핑 정보가 체인에 기록됩니다. 이후 발생하는 모든 인바운드 및 아웃바운드 트랜잭션은 AccountId를 기반으로 처리되어 사용자가 프로토콜 전반에 걸친 단일 통합 상태를 유지할 수 있습니다.

이 통합을 통해 Unified Account는 여러 프로토콜에 걸쳐 매끄러운 접근과 제어를 제공하여, 단일 통합 프레임워크 내에서 블록체인 자산과 데이터를 효율적으로 관리하고 프로토콜 간 호환성을 촉진할 수 있습니다.
